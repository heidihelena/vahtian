Let S be any solver that satisfies the three conditions below. C1: every adequate account must specify what the solver represents. We define a role as any function that some component must discharge, and by definition every role is discharged by exactly one component.

Four are necessary: given the premises, a solver lacking them cannot solve the problem at all. Every solver in this model therefore exhibits them. As specified above, all four are individually required and jointly sufficient (Section 2).

The Constraint explanation holds that every failure arises from a missing representation. On this view, all solvers that fail do so for the same reason. The Capacity account predicts instead that every failure is a resource limit, which is the claim this paper adjudicates.

How this account could be wrong

Every adequate solver exhibits all six roles. If a solver were found that solved the problem while lacking one, the account would be false. It might possibly be that some solvers could perhaps avoid the sixth role entirely, and that would refute the claim outright.
