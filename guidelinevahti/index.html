A treatment guideline also makes the impact quantitative — projected NNT, survival, toxicity, or cost per recommendation — which can feed the importance/priority ranking. (Two reference guidelines are in progress: a diagnostic pulmonary-nodule guideline and a lung-cancer treatment guideline.)

What it does

  • RAND/UCLA two-region consensus — median, IQR, distribution, and a state (consensus for/against · uncertain · no consensus) with a configurable threshold and a disagreement rule.
  • Delphi rounds — round-by-round trajectory, stability between rounds, and a stop rule (consensus, stable “won’t converge”, or round cap).
  • Importance × feasibility priority map — a 7-cut quadrant plot that ranks an implementation priority list (do-first → deprioritise).
  • Chance-corrected ordinal agreement — interval Krippendorff’s α across the statement set, more honest than IQR alone.
  • GRADE / EtD recommendations — consensus + evidence certainty become a recommendation: strong “recommend” or conditional “suggest”.
  • Between-round feedback — a per-panelist blinded feedback file (their prior vote + the group distribution) to run the next round.
  • De-identified & private by design — aggregates only, no panelist ever named; the AI is never a panelist; nothing uploads (no network calls at all).
  • Part of the evidence ladder — keyed to the same protocol the rest of the Vahtian house uses, so screening (ReviewVahti) and consensus (GuidelineVahti) line up.
