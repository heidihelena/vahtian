# Vahtian field-note icons

Reusable SVG icons for editorial, Learn, product, and social surfaces. They use
the same rough-note logic as the metaphor library: light construction marks,
uneven medium outlines, and one pressed-in violet gesture.

## Icons

- `student.svg` - one researcher or learner
- `team.svg` - a research group, lab, or doctoral-school cohort
- `book.svg` - reading, literature, methods, or learning material

The files contain no font, script, external request, or embedded raster image.
Use them directly with `<img>` or inline the SVG when a page needs finer layout
control. Keep their aspect ratio and do not recolor them with state hues.
